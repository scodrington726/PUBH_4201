# Lab 2: Mayo Clinic PBC Trial Analysis

This project analyzes the relationship between age and cholesterol levels in the Mayo Clinic PBC trial dataset.

## Files

- `Lab2.ipynb` — Jupyter notebook containing the analysis
- `Lab2.html` — rendered version of the notebook

## Data Source

The dataset is loaded directly from the original online source using Python and pandas.

## How to Run

1. Open `Lab2.ipynb` in JupyterLab.
2. Make sure pandas and matplotlib are installed.
3. Run all cells from top to bottom.

The notebook will load the data, clean missing values, perform the analysis, create the visualization, and display the interpretation.
